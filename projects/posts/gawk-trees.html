gawk-trees

[ View Source on GitHub ]

"gawk-trees" is a project I started working on as a final assignment for one of my classes as a senior at UCI, said class centering around learning UNIX-based operating systems, but the project has since developed into something I've had the opportunity to work on part-time in an effort to help improve the logistics of my professor's lab's research. Professor Hayes' research, as well as the work as many others, requires the parsing of huge amounts of data, and the tool of choice for those like my professor for that kind of task is AWK. This extension seeks to provide a full interface for working with hierarchical binary trees as the primary relational data structure for an AWK program, as opposed to the usual hash maps under the hood for its associative arrays. The project is still in continuously development, but thus far I've managed to achieve up to five-fold memory efficiency while maintaining under two-fold runtime to that of native gawk, and I've also recently improved the underlying data structure to work safely with multithreading for multiple Linux platforms.

Along the way, one of the most interesting and challenging problems I had to solve was to further reduce the memory profile of the extension using knowledge about memory alignment for pointers in C, where the minimum alignment on any Linux platform for a pointer to an important struct type in the extension allows for a few bits to store a small integer within each of those pointers themselves. With a bit of knowledge of bit manipulation to keep both the pointers and the integers operational simultaneously, I was able to eventually integrate the change successfully without breaking any of the twenty-plus existing features. I really enjoy learning about the low level details of programming languages and how they relate to the hardware, so I was ecstatic to be able to create the chance to apply that knowledge to make an impact.

You can find more profiling data and documentation at the GitHub link above, if you're looking to process large amounts of data on a shared server or otherwise, please do check it out, I hope it proves useful to you!
